# Radio Recorder

Консольная программа для непрерывной записи аудиовхода в WAV или MP3. По умолчанию она пишет в WAV, начинает файлы на границе каждого 10-минутного интервала и хранит записи в нумерованных папках по дням.

## Управление

При запуске в консоли открывается меню:

- `1` — включить или остановить запись. На главном экране видно время старта или имя текущего файла.
- `2` — показать и выбрать аудиоустройство.
- `3` — изменить устройство, длительность сегмента, срок хранения, папку и формат имени файла.
- `4` — открыть папку записей в Проводнике.
- `5` — открыть подтверждение выхода. Нажмите `1`, чтобы завершить запись и выйти, или `0`, чтобы вернуться. Во время подтверждения запись продолжается. В интерактивном меню `Ctrl+C` также запрашивает подтверждение.

По умолчанию интерфейс открывается на английском. Для переключения нажмите `3` (Settings), `6` (Language / Язык), затем `2` (Русский) или `1` (English). Язык меняется сразу и сохраняется между запусками.

Пока идёт запись, можно открыть папку, посмотреть устройства и изменить настройки для следующего запуска записи. В настройках нажмите цифру у нужной строки, введите значение и нажмите Enter. Esc действует только при подсказке на экране: в редакторе поля отменяет ввод, в списке устройств возвращает назад. В списке устройств R обновляет список, стрелки влево и вправо переключают страницы. В небольшом окне PgUp и PgDn прокручивают экран.

Чтобы вернуть настройки по умолчанию, нажмите `3` → `7`, затем `1` для подтверждения или `0` для отмены. Сброс возвращает английский язык, аудиовход Windows по умолчанию, стандартную папку записей, файлы по 10 минут, хранение 1000 часов и шаблон `%H_%M_%S`.

## Файлы приложения

В **Настройках** (`3`) пункт `8` выбирает формат: `1` — WAV, `2` — MP3. Пункт `9` выбирает постоянный битрейт MP3: 64, 96, 128, 160, 192, 224, 256 или 320 кбит/с. По умолчанию — 128 кбит/с. Для MP3 выберите моно- или стереовход. Настройки применяются при следующем включении записи. Очистка архива учитывает оба расширения.

Настройки создаются при первом запуске в `%APPDATA%\RadioRecorder\settings.toml`. Значения по умолчанию входят в программу; рядом с `.exe` файл настроек не требуется. По умолчанию записи лежат в `%USERPROFILE%\Music\RadioRecorder`.

В Windows x64 релизная сборка включает LAME и MSVC runtime статически. Для запуска нужен один `radio-recorder.exe`.

## Сборка

Для сборки под Windows x64 нужны Rust MSVC и инструменты C++ из Visual Studio Build Tools с Windows SDK. Cargo компилирует LAME из исходников. Из этой папки выполните:

```powershell
cargo build --release
```

Исполняемый файл появится в `target\release\radio-recorder.exe`.

## Источник звука

Меню **Аудиоустройства** перечисляет входы Windows: микрофоны, Line-In, USB-аудиоустройства и виртуальные кабели. Для звука, который просто воспроизводится через колонки или браузер, нужен вход loopback/виртуальный аудиокабель: программа пока не захватывает выход Windows напрямую.

## CLI

`radio-recorder.exe --list-devices` показывает входы без запуска меню. Чтобы задать формат и битрейт при запуске, используйте, например, `--audio-format MP3 --mp3-bitrate 192`. Также поддерживаются `--device`, `--directory`/`-d`, `--format` (шаблон имени файла), `--max-age` (например, `1000h`), `--config` и `--help`.
